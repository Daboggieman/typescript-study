Instructions
Using `Math.sqrt`, write a function that efficiently checks whether `n` is prime (only test divisors up to the square root of `n`).

Expected function
```ts
function is_prime(n: number): boolean {
  return false;
}
```


Here is a possible program to test your function :
```ts
console.log(is_prime(17));
console.log(is_prime(18));
console.log(is_prime(2));
console.log(is_prime(1));
```

And its output :
```text
true
false
true
false
```
