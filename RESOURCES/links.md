# Useful TypeScript Resources

A curated list of helpful TypeScript learning resources, tools, and references.

## Official Documentation

- [TypeScript Official Handbook](https://www.typescriptlang.org/docs/) - Comprehensive guide from basics to advanced topics
- [TypeScript Playground](https://www.typescriptlang.org/play/) - Online editor for experimenting with TypeScript
- [TypeScript GitHub Repository](https://github.com/microsoft/TypeScript) - Source code and releases

## Learning Resources

### Tutorials & Courses
- [TypeScript Deep Dive](https://basarat.gitbook.io/typescript/) - Free online book by Basarat Ali Syed
- [TypeScript Tutorial](https://www.typescripttutorial.net/) - Practical examples and exercises
- [Egghead.io TypeScript Courses](https://egghead.io/technologies/typescript) - Video tutorials from experts

### Books
- "Programming TypeScript" by Boris Cherny
- "Effective TypeScript" by Dan Vanderkam
- "TypeScript Quickly" by Yakov Fain and Anton Moiseev

## Tooling & Utilities

### Linters & Formatters
- [ESLint](https://eslint.org/) - Pluggable JavaScript/TypeScript linter
- [Prettier](https://prettier.io/) - Opinionated code formatter
- [@typescript-eslint/parser](https://typescript-eslint.io/) - ESLint parser for TypeScript

### Build Tools
- [tsc](https://www.typescriptlang.org/docs/handbook/compiler-options.html) - TypeScript Compiler
- [ts-node](https://typestrong.org/ts-node/) - TypeScript execution environment for Node.js
- [tsx](https://github.com/esbuild-kit/tsx) - Fast TypeScript execution (used in this project)
- [swc](https://swc.rs/) - Super-fast TypeScript/JavaScript compiler

### Testing
- [Vitest](https://vitest.dev/) - Fast Vite-based test framework (used in this project)
- [Jest](https://jestjs.io/) - Popular JavaScript testing framework with TypeScript support
- [Testing Library](https://testing-library.com/) - DOM testing utilities
