# Docker Practice

This directory contains Docker exercises designed to help you learn containerization with TypeScript and Node.js applications.

## Directory Structure
- `01_absolute_basic/` - Introduction to Docker concepts
- `02_easy/` - Basic Dockerfile creation and container running
- `03_fair/` - Multi-container applications with docker-compose
- `04_intermediate/` - Multi-stage builds and optimization
- `05_hard/` - Production-ready Docker configurations
- `06_very_hard/` - Advanced networking and storage concepts
- `07_expert/` - CI/CD integration and orchestration

Each subdirectory contains exercises that build upon the previous ones, helping you progress from basic containerization to advanced Docker usage in TypeScript projects.
